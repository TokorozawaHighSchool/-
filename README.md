# Sugoroku Game

このプロジェクトは、JavaScriptとHTMLを使用して作成されたシンプルなすごろくゲームです。プレイヤーはサイコロを振ってボード上を移動し、最初にゴールに到達したプレイヤーが勝者となります。

## プロジェクト構成

- `src/index.html`: ゲームのHTML構造を定義しています。ゲームボードやプレイヤーの情報を表示するための要素が含まれています。
- `src/main.js`: ゲームのロジックを実装しています。プレイヤーの移動、サイコロの振り方、ゲームの進行状況を管理する関数が含まれています。
  - 主な関数:
    - `rollDice`: サイコロを振る
    - `movePlayer`: プレイヤーを移動させる
    - `checkWin`: 勝者を確認する
- `src/styles.css`: ゲームのスタイルを定義しています。ボードやプレイヤーの見た目を整えるためのCSSルールが含まれています。

## セットアップ手順

1. このリポジトリをクローンまたはダウンロードします。
2. `src/index.html`をブラウザで開きます。
3. ゲームを開始し、サイコロを振ってプレイします。

## 遊び方

1. プレイヤーは順番にサイコロを振ります。
2. サイコロの出た目に応じて、ボード上を移動します。
3. 最初にゴールに到達したプレイヤーが勝者です。

楽しんでプレイしてください！
